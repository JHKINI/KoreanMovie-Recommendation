# 현재 구현 상태

기준일: 2026-10-06

최신 요구에 따라 프론트 없이 데이터 준비·저장·검색·추천·리뷰 조회·HTTP API를 구현했다.
2026-10-01의 인계 원문은 `docs/HANDOFF_2026-10-01.md`로 보관한다. 이후 실제 구현 상태는 이 문서를 기준으로 한다.

## 완료

- 원본 검사, 영화별 프로필, 개별 리뷰와 내부 영화 ID 연결.
- scikit-learn TF-IDF, 범주/수치/리뷰 유사도 저장.
- 장르 후보 선정, 자기 제외, 유사도 상위 20개, 보정 평점으로 최종 추천.
- 실제 평점순 리뷰 조회. 결측 평점은 텍스트에 보존.
- 버전별 파일 저장, 해시/ID 순서 검사, 실패 시 이전 정상 버전 유지.
- 저장 데이터를 시작 때 한 번 로딩하는 검색·추천·리뷰 API.
- 제목만으로 상세·추천·리뷰 조회. 기존 ID 경로도 제목을 받을 수 있다.
- 동명이작 후보는 409 응답으로 표시하고 제목 조회 API의 개봉일/감독 조건으로 구분한다.
- 코드 내 함수 설명(docstring), 라이브러리 선택 이유와 실행 안내.

## 확인된 검사

- 원본 26,801행 → 추천용 리뷰 26,768행 → 영화 프로필 214개.
- 실제 TF-IDF 행렬 214×5,000.
- 모든 영화 214개의 추천 동작과 높은/낮은 평점 리뷰 정렬 428가지 검사 통과.
- 기존 원본 검사 테스트 8개와 신규 파이프라인/HTTP 테스트 25개, 총 33개 통과.
- 실제 데이터에서 제목 조회와 ID 조회의 결과 일치, 제목 특수문자/빈 입력/동명이작 처리를 확인했다.
- 원본 CSV는 준비 전후 SHA-256이 동일하다.

현재 프로젝트 `.venv`의 Python 3.12에서 검증했다. 정확한 패키지는 `requirements.lock.txt`에 기록한다.
현재 버전의 보고서는 `artifacts/recommendation/CURRENT.json`이 가리키는 폴더의 `evaluation.json`에 있다.

## 실행과 다음 범위

폴더 정리 후 현재 백엔드 코드는 프로젝트 루트에, 기존 평점 예측 실험은 `archive/rating_prediction`에 있다.
추천 참조 코드는 `archive/recommendation_reference`, 이전 산출물은 `archive/old_artifacts`에 보관한다.
현재 정상 데이터는 `artifacts/recommendation/CURRENT.json`이 가리키는 위치를 유지했다.

`docs/BACKEND_GUIDE.md`의 실행 명령과 라이브러리/점수 설명을 참고한다.
원본 CSV를 새로 준비하면 `run_pipeline.py`를 실행하고 API 서버를 재시작한다.
새 평점 예측 모델/Ridge/LSTM 학습은 이번 작업에서 실행하지 않았다.
TF-IDF fit은 리뷰 어휘/빈도 통계를 계산하는 준비 과정이다.
가중치 최적화와 사람의 추천 만족도 검증, 공식 영화 식별자 연결, 크롤러, 프론트는 이후 범위다.
